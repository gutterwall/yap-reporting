Browser setup (no command line needed)

1. Rename ENABLE_SETUP.off to ENABLE_SETUP (in this folder) with your SFTP program.
2. Visit https://YOUR-YAP-SITE/reporting-api/setup   (add /yap or your folder if YAP is not at the site root)
   If that says "Not Found", try https://YOUR-YAP-SITE/reporting-api/public/index.php/setup
3. Download setup-code.txt from this folder and enter the code on the page.
4. When finished, click "Finish and lock setup" (or delete ENABLE_SETUP yourself).

While ENABLE_SETUP is absent, the setup page does not exist (returns "not found").
